#  IPL 2025 Auction Analysis

##  Project Overview

This project analyzes the IPL 2025 auction dataset to understand player prices, team spending, and player auction details using Python.

##  Objectives

* Load and explore the IPL 2025 auction dataset.
* Clean the dataset and handle missing values.
* Analyze player prices and team spending.
* Visualize auction data using charts.
* Identify useful insights from the dataset.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

##  Project Files

* `ipl_auction_simple.ipynb` – Jupyter Notebook containing the data analysis.
* `ipl_2025_auction_cleaned (1).csv` – Cleaned IPL 2025 auction dataset.

##  Project Workflow

1. Load the dataset.
2. Explore the data.
3. Clean the dataset.
4. Perform data analysis.
5. Create visualizations.
6. Identify key insights.

##  How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Install the required libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 3. Open Jupyter Notebook

```bash
jupyter notebook
```

### 4. Run the notebook

Open `ipl_auction_simple.ipynb` and run the cells sequentially.
